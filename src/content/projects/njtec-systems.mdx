A lead-focused marketing site for a client who installs security cameras for homes and businesses across Mississauga and the GTA. It covers services, pricing, service areas, an installation gallery, an FAQ, and a quote form, with a mobile call bar so visitors on a phone can reach the client in one tap. Every page is prerendered to static HTML, and the only server code is a single function that validates quote requests, drops bot submissions caught by a honeypot field, and emails the rest through Resend. Business details, pricing, and service areas live in data files rather than in the markup, so updating them never means editing a page. They also feed the structured data for search.
